# PM 0.20 model economy

PM now treats Sol in Codex and Opus in Claude Code as the ordinary interactive
session tier. Astra and Fable are bounded review seats invoked only through
Ringer for a named uncertainty, material risk, or applicable evidence requirement.

Ordinary Ringer work uses the least costly locally proven model that can satisfy
the executable contract. Reviewers receive compact evidence packets and return
findings; the ordinary orchestrator owns fixes and integration. Session succession
preserves the ordinary tier. The routing is evaluated by account capacity consumed
per accepted outcome, plus retries and human intervention.

Source and generated-package regressions enforce the boundary. The full repository
suite and Codex package validation are the release checks.
