Finding: Unicode horizontal whitespace inside a policy-section label is still treated as genuine absence, silently selecting legacy shipping — the same failure mode correction 2 closed for ASCII space/tab.
Evidence: `library/skills/agent-operations/build-swarm/scripts/agreement_contract.py:148` (and the byte-identical `pm/scripts/agreement_contract.py`) joins the label words with `[ \t]+`, which matches only ASCII space and tab. Scratch reproduction through the real acceptance CLI (fixtures from `tests/test_pm_evidence_channels.py`): an intent containing a fully valid approved `dc-autonomy-v1` agreement under `## Execution agreement` (NBSP), ` ` (en space), or `　` (ideographic space), with a legacy record carrying no evidence requirements or channels, returns exit 0 / `status: shipped` in all three cases, while the identical intent with ASCII double-space or tab exits 2. The shared runtime helper returns `None` (genuine absence) for the NBSP variant, so `agreement.load` on the build side raises "expected exactly one ## Execution agreement heading" — a loud refusal — while the ship side silently drops all channel enforcement. The fix docstring ("any horizontal-whitespace run between the label's words") and the release note ("Malformed policy headings fail closed rather than silently selecting legacy behavior") both promise more than `[ \t]+` delivers.
Impact: A heading that renders identically to the canonical one (NBSP is produced by Option+Space on macOS and survives copy-paste from rendered HTML) hides an approved agreement from the delivery validator: code-complete work can validate `shipped` with no UI/state evidence and no channel identity checks, exactly the outcome the round-2 P2 correction was meant to prevent, with a rarer trigger.
Fix: In `locate`, treat any Unicode horizontal-whitespace run between the label words as an attempted heading (e.g. join with a class including ` `, ` `-` `, `　`, or use `[^\S\n]+`), keep the exact-canonical acceptance check unchanged, resync the vendored/generated PM copies, and add NBSP cases beside the existing space/tab regressions.
